El concepto

01

La X es el centro

Dos elementos cruzados: dos partidos en el fixture, dos equipos enfrentándose, las hojas del calendario tachadas. La X es donde el deporte ocurre.

02

Tipografía bloque deportivo

Archivo Black para el logotipo: peso editorial-deportivo (Panenka, El Gráfico) que se diferencia del SaaS-genérico tipo Inter/Helvetica.

03

Color como afirmación

Verde cancha profundo + naranja silbato del árbitro. Sin pasteles, sin gradientes innecesarios. Un sistema confiado.

→ Reglas de aplicación El Cancha Profundo es el color identitario (header, footer, brand mark). El Lime es el color de acento positivo (estados de éxito, CTAs secundarios, badges). El Silbato es para acciones primarias y alertas que requieren atención. Nunca usar gradientes en logos, badges o íconos. Sí permitidos en hero sections grandes.
